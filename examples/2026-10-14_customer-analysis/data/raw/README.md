# Synthetic input

`customers.csv` is generated by `../../src/generate_data.py` with seed `20261014`. All rows and identifiers are artificial. Plan is assigned independently of the churn probability; the generator explicitly raises churn probability for short tenure and for two or more support cases. The strong support-case association is therefore planted in the synthetic data, not an empirical discovery. The generator is included so the example can be reproduced; the checked-in CSV is the fixed input for the recorded runs.
