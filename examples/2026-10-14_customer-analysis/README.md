# Customer churn analysis (synthetic demonstration)

Status: closed · created 2026-10-14 · last verified 2026-10-14

This worked example demonstrates a handoff across two analytical runs. It uses a fully synthetic dataset generated by `src/generate_data.py`; it contains no real customer information.

## Research question

Which of two candidate factors is associated with customer churn in this synthetic dataset: subscription plan or recent support-case count?

## Scope and limitations

The example demonstrates a simple, reproducible descriptive analysis and the experiment's record-keeping workflow. It does not estimate causal effects, validate a real customer-retention strategy, or support decisions about actual customers.

## Predeclared checks

- Run 1: compare churn rates for monthly and annual plans. The working hypothesis is that the absolute difference between the two plan-group rates is at least 5 percentage points. A smaller absolute difference does not meet this example's support threshold; it is not proof of equivalence.
- Run 2: compare churn rates for customers with at least two recent support cases and those with fewer than two. The follow-up hypothesis is that the higher-support group has at least a 10 percentage-point higher churn rate.
- Both checks are descriptive. No confidence interval, significance test, adjustment, or causal interpretation is claimed.

## Reproduce

From this directory, using Python 3.10+ and no third-party packages:

```bash
python3 src/generate_data.py
python3 src/analyze.py plan
python3 src/analyze.py support
```

`generate_data.py` uses a fixed seed. The checked-in CSV is the experiment input; regenerate it only when intentionally restarting this example, then update its manifest and run records.
